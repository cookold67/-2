ДИСКЛЕЙМЕР
Данный репозиторий создан исключительно в образовательных и исследовательских целях в рамках выполнения лабораторной работы по информационной безопасности. 

Веб-приложение написано на стандартных модулях Python (http.server, sqlite3). Содержит две уязвимости из OWASP Top 10:SQL Injection (POST /login) — прямая подстановка логина и пароля в SQL-запрос через f-string, Path Traversal (GET /file) — отсутствие проверки пути к файлу.
Скрипт на модуле urllib автоматически проводит две атаки без браузера. Вход под администратором без пароля через SQL-комментарий (admin' --), чтение закрытого файла secret.env за пределами корневой папки через переход на уровень выше (../secret.env).
Патч закрывает обе уязвимости. SQL-запрос переведен на безопасную параметризацию. Для файлов добавлена проверка абсолютного пути (os.path.abspath) — выход за пределы папки public блокируется ошибкой 403 Forbidden.
